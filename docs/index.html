    Datenquelle

    Die Station wird alle 5 Minuten von GitHub Actions abgefragt (Workflow „Wetterdaten sammeln“). Die Messwerte liegen als CSV-Dateien im Zweig daten deines Repositorys.

    Station ändern: im Repository die Datei config.json öffnen, beim Eintrag source_url die neue Adresse eintragen und speichern.
